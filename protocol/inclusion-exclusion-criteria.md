# Inclusion and Exclusion Criteria

## Inclusion Criteria
| ID | Criterion |
|----|-----------|
| IC1 | Study addresses edge, fog, or multi-access edge computing |
| IC2 | Study is set in, or explicitly targets, one or more African countries |
| IC3 | Peer-reviewed article, conference paper, or credible grey literature |
| IC4 | Published within the defined time window |
| IC5 | Full text available in English |

## Exclusion Criteria
| ID | Criterion |
|----|-----------|
| EC1 | Edge computing mentioned only in passing |
| EC2 | No African context or relevance |
| EC3 | Editorials, opinion pieces, abstracts only, posters |
| EC4 | Duplicate publications (keep the most complete version) |
| EC5 | Full text unavailable |
